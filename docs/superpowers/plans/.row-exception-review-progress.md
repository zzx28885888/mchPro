## Task 1 Decisions / 任务 1 决策

- **Ruling:** A `CORRECT` decision includes the corrected row even if its mapped key still duplicates a prior row. / **裁定：** `CORRECT` 会将已修正行纳入结果，即使映射后的键仍与前一行重复。
- **Why / 原因:** The user explicitly chose to correct the exception; silently dropping the corrected row would make the correction invisible in the revised output. / 用户明确选择了修正异常；若仍静默跳过，修正不会出现在修订结果中。
- **Cost if wrong / 误判代价:** Users may retain a duplicate they expected deduplication to remove; the duplicate issue remains reviewable and can be skipped explicitly. / 用户可能保留本以为会去重的重复项；该重复异常仍可被复核并明确跳过。
- **Ruling:** Add `reviewedRowsSkipped` to revised counts when review decisions are present. / **裁定：** 有复核决定时，在修订计数中增加 `reviewedRowsSkipped`。
- **Why / 原因:** Existing duplicate/blank counters describe automatic cleanup; user-directed skips need a distinct count. / 现有重复/空行计数表示自动清洗结果，用户手动跳过应单独计数。

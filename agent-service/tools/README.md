# Deprecated in V1.6

中文：此目录下的 Python 注册表示例不再承担业务工具执行。当前产品路径由 Python/LangGraph 调用 Spring Boot Java Tool Registry。

English: The Python registry examples in this directory no longer execute product business tools. The current product path is Python/LangGraph calling Spring Boot's Java Tool Registry.

V1.6 no longer uses the Python Tool Registry for business execution.

The authoritative Tool Registry is now in:

`backend/src/main/java/com/example/agent/tool`

Python/LangGraph calls Java over HTTP.
